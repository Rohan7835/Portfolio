# Rohan Chauhan — Portfolio

A modern, responsive personal portfolio for Rohan Chauhan, Senior Software Engineer. The site highlights professional experience, selected projects, technical capabilities, recognition, education, and contact information.

## Built with

- React 18
- React Router
- Vite
- Modern CSS animations and responsive layouts

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```
